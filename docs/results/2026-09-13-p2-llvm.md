# 2026-09-13: patched LLVM 22.1.8 builds and emits knc64-x87 code

Host: Arch/CachyOS, clang 22.1.8 as the build compiler, 16 threads.
`toolchain/llvm/build.sh all` with patches 0001 to 0005 (`toolchain/llvm/patches/`).
Build time about 55 minutes including one restart after a mangled patch.

`build.sh check` output (probe sources in `docs/research/abi-and-toolchain.md`):

## Readings

- Two `select`s (`int` and `long`) compile without CMOV: patch 0001 makes
  `-cmov` effective in 64-bit mode and patch 0005 supplies the 64-bit
  branch expansion.
- `double m(double a, double b)` receives `a` at `8(%rsp)` and `b` at
  `0x10(%rsp)` (stack arguments, LLVM's existing SSE-off rule) and returns
  on the x87 stack (patch 0002); the unpatched compiler rejected this
  function with "SSE register return with SSE disabled".
- Zero suspect instructions: `-nopl` plus patch 0003 remove multi-byte NOP
  padding, `-fcf-protection=none` removes `endbr64`.
- The stock clang 22.1.8 could not produce either object; see the
  measurements table in `docs/research/abi-and-toolchain.md`.
