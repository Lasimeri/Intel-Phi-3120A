# 2026-09-13: first RGCR reset

Host kernel 7.2.3-1-cachyos. Command: `sudo host/target/debug/phictl reset --timeout 120`
(binary built before the POST-code decoder change, so it printed only the
low byte of the register).

```
before: postcode 0x30, spad2 0x040001c1
after 9.32s: postcode 0x31, spad2 0x040001c1 (ready=true apic_id=224 download_addr=0x4000000)
```

## Readings

- The `RGCR` bit-0 reset works from userspace over VFIO. The bootstrap
  cleared and re-announced `SPAD2` with the identical value (download
  address 64 MiB, BSP APIC ID 224) after 9.32 s including the mandatory
  1 s settle.
- The POST register changed across the reset (low byte `'0'` before,
  `'1'` after), so it is live. The `"0c"` seen at first contact was the
  state the card was left in after host power-on, not a stale register;
  why the bootstrap sat at "Cache C code" while also flagging ready in
  `SPAD2` is not explained by the available documents. The next run, with
  the full-pair decoder and the 10 ms trace, records the complete
  sequence.
