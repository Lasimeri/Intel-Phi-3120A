# mandel_vpu.S

Generated by `knc-mvex-gen mandel` (host/crates/knc-mvex): the Mandelbrot
inner loop on the card's vector unit, 8 doubles per instruction.

```
void mandel8_vpu(const double *c, double *out, int maxiter);
   c[0..7] = cr, c[8..15] = ci (64-byte aligned)
   out[0..7] = escape count as double, out[8..15] = |z|^2 at exit
```

Register use: zmm0 cr, zmm1 ci, zmm2 zr, zmm3 zi, zmm4 zr^2, zmm5 zi^2,
zmm6 count, zmm7..9 the constants 2, 4, 1 (loaded from a 64-byte aligned
table through `lea`), zmm10 |z|^2, zmm11 2 zr; k1 the active lanes.

The loop, per trip: `k1 = k1 & (zr^2 + zi^2 < 4)` with `vcmppd` (its
write mask ANDs into the result, ISA reference table 6.3); `kortest`
leaves when no lane is active; then under mask k1, `zi = 2 zr zi + ci`
(`vmulpd` then `vfmadd213pd`), `zr = zr^2 - zi^2 + cr`, the two squares,
and `count += 1`. Lanes that escaped keep their registers, so their
squares still hold the exit magnitude. A scalar counter in r8d bounds the
trips by maxiter. Same arithmetic and order as the AVX2 path in
mandel-vpu.c, so both machines produce identical counts.
