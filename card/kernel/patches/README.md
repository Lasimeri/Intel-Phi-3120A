# card/kernel/patches

The patch series is generated in phase P3 with `git format-patch` against
a pinned mainline tag recorded in `SERIES` (format: one patch filename per
line, tag on the first line). The intent of each patch is fixed already;
see `../README.md`.

Until then this directory holds only this file, so that nobody mistakes a
draft for an applied patch. Drafts of the new files live in `../platform/`.
