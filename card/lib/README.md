# card/lib

Libraries for programs running on the card, as opposed to `card/examples`,
which are programs.

| Directory | What |
| --- | --- |
| `knc` | the 512-bit vector unit as a C ABI: bit packing at every width, block copy, and the C++ layer over them |
| `knc-rs` | the same library seen from Rust |
| `knc-py` | the same library as a module built into the card's CPython |
| `knc-js` | the same library as a module compiled into the card's QuickJS |

All four exist for one reason: **no compiler emits Knights Corner vector
instructions.** Not clang, not rustc, not the card's own clang, not
anything since Intel's k1om toolchain. The kernels are hand-encoded MVEX
generated by `host/crates/knc-mvex`, so they are written once and shared,
rather than pasted into every program that wants them.

The order is `card/lib/knc/build.sh` first: it installs `libknc.a` and the
headers into the sysroot and packages them for `/opt/phi`, and everything
else links against what it installed. Then any of `card/lib/knc-rs/build.sh`,
`card/userland/components/cpython.sh` (with `PHI_PYTHON_EXTRA_SRC` and
`PHI_PYTHON_SETUP` pointing at `knc-py`) and
`card/userland/components/quickjs.sh`.

`docs/howto/languages-on-the-card.md` covers reaching this from each of the
five languages.
