# card/initramfs

The card's whole root filesystem is a compressed cpio built on the host
and loaded at `2 * bootaddr` by `phictl boot`.

## Layout

```
/init                 Rust init (card/userland/components/init.md)
/bin, /sbin           busybox applets (symlinks)
/lib/modules/<ver>/   phinet.ko and any other modules
/usr/bin              dropbear, dbclient, scp, qjs, python3, tcc, cc ...
/etc/dropbear/        host keys generated by phictl
/etc/passwd, group    root plus one user; ssh keys in /root/.ssh
/etc/phi/             ring base, host IP, card IP (also on the cmdline)
```

## Build script (phase P4)

`mkinitramfs.sh`: assembles the tree from the component install
prefixes, runs `phi-isa-audit` on every ELF and refuses to pack if any
reports illegal instructions, then `cpio -o -H newc | zstd`. Records the
component versions and the audit summary in a manifest inside the image
and in `docs/results/`.
